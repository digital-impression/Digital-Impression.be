Vragen

Wat klanten vaak vragen.

Wat kost een naam op een handdoek?

Borduren op badlinnen begint bij € 1,25 voor een washandje. Voor grotere stukken of een eigen tekening vragen we het je gewoon even.

We willen ons logo op werkkledij. Hoe gaat dat?

Bezorg ons je logo. We maken het één keer klaar voor de borduurmachine, de instelkost begint bij € 15. Daarna kan het op zoveel stukken als je wil.

Kan ik op woensdag langskomen?

Op woensdag werken we op afspraak. Bel even naar 057 20 22 06 en we spreken een uur af.

Kunnen jullie ook op leder borduren?

Ja, we borduren zowel op stoffen als op lederwaren. Breng het stuk mee, dan bekijken we samen wat mooi uitkomt.

Zijn jullie soms met verlof?

Ja, bijvoorbeeld tijdens de herfstvakantie. Op deze site zie je altijd meteen wanneer we gesloten zijn.
